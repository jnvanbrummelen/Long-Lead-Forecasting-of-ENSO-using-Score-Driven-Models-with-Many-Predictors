## Data Description

### Data 

The data is available upon request. Please send an e-mail to <desislava.petrova@isglobal.org> to request the data. 

The data should be stored in the xlsx file `data/Book1982_2025_HIGHRES_OISST.xlsx`. The first column contains the date in year-month format. The remain 25 colums contain the Niño3.4 index (`EN3.4`) and the 24 explanatory variables. There are 516 rows (data from 1982-1 tot 2024-12, where for some explanatory variables the last two months are missing). 

The Niño 3.4 index was derived from the NOAA OI SST V2 High Resolution Dataset. For more details about how these data were obtained, we refer to the paper.
  
### Intermediary data files 
The following files are intermediary (expensive to recompute):

| File(s) | Generated by | Description |
|---|---|---|
| `intermediary_data/insample/monthly_means.csv`, `intermediary_data/insample/parameters/*.csv`, `intermediary_data/insample/paths/*.csv` | `01_run_insample.py` | in-sample parameter estimates and filtered paths (~1 hour to compute) | 
| `intermediary_data/outsample/forecast_errors/*.csv`, `intermediary_data/outsample/forecasts/*.csv`, `intermediary_data/outsample/parameter_estimates/*.csv` | `03_run_outsample_noG2S.py` and  `04_run_outsample_G2S.py` | forecasts, forecast errors and parameter estimates per horizon (days to compute) | 
| `intermediary_data/outsample/combined_forecast_errors/*.csv`, `intermediary_data/outsample/anomaly_forecasts/*.csv`  | `05_aggregate_outsample_results.py`  | merges all forecast errors into single file per horizon (seconds to compute) | 
| `intermediary_data/realoutsample/demean_forecasts.csv`, `intermediary_data/realoutsample/forecasts.csv`, `intermediary_data/realoutsample/parameter_estimate/*.csv` | `06_run_realtime_outsample.py`  | real-time out-of-sample forecasts and corresponding parameter estimates (~1 hour to compute) |

## Reproducing the Results

### Python

All Python scripts must be run from the `python_code/` directory:

```bash
cd replication_EN/python_code
```

#### In-sample results

To obtain in-sample results, run:
```bash
python 01_run_insample.py # in-sample estimation
python 02_Table1_2_A4_A5_A6_A7_construction.py # construction of in-sample tables
``` 
##### Quick reproduction of in-sample results
Use pre-computed parameters can regenerate tables and figures by running only `02_Table1_2_A4_A5_A6_A7_construction.py`.

#### Out-of-sample results

To obtain out-of-sample results, run:
```bash 
python 03_run_outsample_noG2S.py # run out-of-sample forecast for the models without general to specific
sbatch 04_run_outsample_G2S.sh  # run out-of-sample forecast for the models with general to specific on 4 nodes
# python 04_run_outsample_G2S.py  # run out-of-sample forecast for the models with general to specific sequentially
python 05_aggregate_outsample_results.py #  aggregate the out-of-sample results 
python 07_mse_table.py # Compute mse-values for Table 3, A.8, A.9, A.10, A.11
python 08_adf_tests.py # Run ADF tests on losses underlying Table 3, A.8, A.9, A.10, A.11
python 09_heatmaps.py # Construct heat maps in Figure 4 and 5
```
Script `04` is the main bottleneck. It features a rolling window estimation of 12 model configurations. The rolling-window estimation is parallelized within each model configuration and forecast horizon using `n_jobs=16` by default.

The script `04_run_outsample_G2S.sh` provides an example Slurm submission script for running `04_run_outsample_G2S.py` on a cluster, where multiple model configurations can be ran in parallel using Slurm job array `--array=0-11%4`. Before submitting the job, replace the placeholder values (`<...>`) with the appropriate settings for your HPC system.
    
##### Quick reproduction of out-of-sample results
Use pre-computed forecasting errors to skip the heavy computations and regenerate all tables and figures:  
```bash
python 07_mse_table.py # Compute mse-values for Table 3, A.8, A.9, A.10, A.11
python 08_adf_tests.py # Run ADF tests on losses underlying Table 3, A.8, A.9, A.10, A.11
python 09_heatmaps.py # Construct heat maps in Figure 4 and 5
```
 
#### Real-time out-of-sample results 
To obtain real-time out-of-sample results, run
```bash 
python 06_run_realtime_outsample.py # construct real-time out-of-sample results
```

### MATLAB

Run the script `m10_mcs.m` from the `matlab_code/` directory to construct model confidence sets for Table 3, A.8, A.9, A.10, A.11. Note: this script uses intermediary data that is output of Python scripts `03`, `04` and `05`. 


### R

Open the project file `r_code.Rpoj` from the `r_code/` directory and run the script `11_enso_plot_hegy_cn_test.R` from RStudio to compute HEGY and Canova-Hansen tests for Table A.1, A.2 and plot Figure 1.


### TeX
Figure 2, 3, 6 and A.1 are obtained using LaTeX pgfplots and intermediary data stored in `output/intermediary_data/` and these `.tex` files should be ran from `/output/figures`. So e.g. 
```bash 
pdflatex Figure2a_filt_cycles_subsample1.tex 
```
and the same for the other `.tex` files.

|---|---|---|---|
